# ISO 45003 互動遊戲｜完整手機版

把桌面原版遊戲整個改成適合手機玩的版本。**遊戲規則和桌面原版完全相同**（直接使用同一份規則程式），只把畫面與操作重新設計給手機：

- 直拿就能玩，字比較大；橫拿時自動變成左右兩欄（左邊夥伴、右邊手牌），平板也適用
- 人物與外觀沿用「手機簡單版」：同樣的角色、配色與跳動動畫
- **夥伴排隊**：一位站在前面處理，其他人在後面排隊
  - 點排隊的夥伴，可以換他上前
  - 前面的夥伴壓力都處理完，會自動換下一位需要幫忙的人上前
- 出牌：點卡牌再點前面的夥伴，或把卡牌往上拖到夥伴身上（手牌可以左右滑動）
- 每回合結算時，用一張說明卡告訴玩家每位夥伴的心情怎麼變、誰離職、為什麼
- 選錯卡時，夥伴會說出提示（`data/bubbles.json` 的 `hint`）
- 有音效與背景音樂、中途離開可以繼續、試玩紀錄可匯出 CSV、離線可玩、自動更新

不需要安裝任何套件或建置，資料夾裡的檔案直接放上網站就能用。

## 和桌面原版的差別

| | 桌面原版 | 完整手機版 |
|---|---|---|
| 規則 | | 完全相同（同一份 `GameEngine.js`，以檔案指紋確認一字不差） |
| 回合數 | 6 回合（每回合 1、1、2、2、3、3 位夥伴） | **4 回合**（1、2、3、3 位），約 3 分鐘 |
| 畫面 | 固定 1920×1080 畫布、強制橫放 | 一般網頁排版，直拿、橫拿都可以 |
| 多位夥伴 | 同時排在畫面上 | 排隊，點選切換 |
| 中途離開 | 進度消失 | 自動保存，可「繼續上次的進度」 |

回合數是用模擬比較後選的：4 回合（1、2、3、3 位）保留了「最後要同時照顧 3 位夥伴」的挑戰，出牌次數約為原版的 2/3，新手完成率從原版的約 82% 提高到約 93%，較適合展場。要改回 6 回合，修改 `data/balance.json` 的 `totalRounds` 與 `rounds` 即可。

## 上線

把這個資料夾**裡面的檔案**全部上傳到網站（GitHub Pages、Netlify、公司網站都可以），保留 `assets/`、`data/`、`js/` 的資料夾結構。`tests/`、`README.md`、`preview.mjs` 不需要上傳（上傳了也沒關係）。

**發布新版時，直接上傳新檔案即可**，不用改任何版本號。已經開過的手機與平板會自動更新：停在首頁的頁面最晚約 5 分鐘內換成新版；正在玩的人不會被打斷，回到首頁時才換。

只有**新增或刪除檔案**時，才需要更新 `sw.js` 裡的 `FILES` 清單（離線時才用得到的檔案要列在裡面）。

## 在電腦上預覽

電腦裝有 Node.js 時，在這個資料夾執行：

    node preview.mjs

然後用瀏覽器開啟 http://127.0.0.1:4175 。不要直接雙擊 `index.html`，遊戲資料需要透過網址載入。

網址參數（測試、展示用）：

| 參數 | 作用 |
|---|---|
| `?seed=12345` | 固定隨機種子，同一個數字每次發牌都一樣 |
| `?demo=1` | 示範模式（固定種子） |
| `?debug=1` | 首頁出現「試玩設定」：功能開關、匯出／清除試玩紀錄 CSV |
| `?tester=小明` | 試玩紀錄裡的試玩者名字 |
| `?e2e=1` | 自動測試模式（關閉音效、縮短等待），給測試程式用 |

## 修改遊戲內容

內容都在 `data/` 的 JSON 檔，和桌面原版相同（欄位說明見桌面原版專案的 `docs/MAINTENANCE.md` 第四節）。資料填錯時，遊戲會顯示「遊戲無法啟動」並寫出哪裡有問題。

要注意：

- 每一筆資料都要保留 `"_reviewStatus": "draft"`。
- 改了資料之後，玩家手機上的舊存檔會自動作廢（避免套用到不同的內容）。
- 困難模式的突發事件固定在第 2、4 回合，寫在規則程式裡。
- 首頁的三隻角色寫在 `js/app.js` 的 `renderCover`。

## 檔案對照

| 檔案 | 用途 |

| `index.html`、`styles.css` | 網頁與外觀（字級、顏色、直式／橫式版面） |

## 資料存在哪裡

全部存在玩家自己那台裝置的瀏覽器，沒有伺服器、沒有雲端同步：

- **存檔**：中途離開或關掉頁面，下次開啟可「繼續上次的進度」；玩完一局就清除。
- **試玩紀錄**：每台裝置各自記錄；展後在每台裝置用 `?debug=1` 匯出 CSV。中途放棄的局會在下次開新局時記成「未完成」。
- **靜音、音量、難度**的選擇。

清除瀏覽器資料、私密瀏覽模式時，這些都會消失。

## 自動測試

    node tests/rules.test.mjs                 # 規則、存檔續玩（不需要瀏覽器，幾秒鐘）
    python3 tests/browser-check.py 16         # 模擬手機玩 16 局並檢查各種操作（約 3 分鐘）
    python3 tests/offline-update-check.py     # 離線與自動更新（約 6 分鐘，加 --kiosk 另測攤位平板情境）

瀏覽器測試需要 Python 3、`pip install playwright` 與 Chrome（路徑可用環境變數 `CHROME_PATH` 指定）。

2026-10-29 驗證結果：規則程式與桌面原版一字不差；1,000 局隨機遊戲、2,239 個中途存檔點續玩後局面完全相同；模擬手機以點選、手指拖曳、換人、換牌、中途重開等操作玩 16 局，每一步畫面都與實際狀態一致、無錯誤；小手機（320×568）、一般手機、橫放皆可完整遊玩；離線與自動更新全部通過。**尚未在真正的 iPhone 與 Android 上測試**，上線前請各完整玩一局。

## 已知限制

- 在同一個網域（例如同一個 GitHub 帳號）同時放桌面版、手機簡單版與這個版本時，三者互不干擾（各自的離線快取、存檔、試玩紀錄名稱都不同）。
- 主畫面圖示的顯示方式由各手機瀏覽器決定。
- 較舊的 iPhone（iOS 15.4 以前）在遊戲中頁首的公司標誌不會自動隱藏，不影響遊玩。
